## Introdução
* Neste primeiro projeto é pretendido desenvolver um módulo de uma dupla lista ligada. Cada ficheiro implementado contém a sua respetiva documentção mais detalhada.
 
## Estrutura de código
* `../src/lib` - Ficheiros .C e .h
* `../src` - Ficheiros main
* `../Doc` - Documentação
 
## Secções
* Módulos 
* Estruturas de dados

## Módulos
* **Dupla Lista Ligada (DLL)**: Implementação de uma lista ligada, com várias operações disponíveis, sendo possível também aceder ao elemento anterior e posterior uma vez que é duplamente ligado.
 
## Estruturas de Dados 
* **DLLNode**: Nodo de ligação da lista ligada, em que consiste num indentificador e o respetivos dados.
* **DLL**: Estrutura da lista ligada, sendo constituida por número máximo de elementos/nodos, primeiro(head) e último(tail) nodo da lista.
 
## Ficheiros
* **DLL.h**: Ficheiro header onde são definidos a estrutura de dados e as funções a implementar para o modúlo.
* **DLL.c**: Implementação das funções do modúlo.
* **main.c**: Ficheiro de teste do modúlo a simular a dupla lista ligada
